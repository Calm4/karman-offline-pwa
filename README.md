# Карман

Небольшое PWA для заметок с офлайн-запуском. Заметки остаются на устройстве; сетевых запросов с их содержимым нет.

Открой сайт в Safari, добавь на экран «Домой», запусти с иконки и дождись готовности офлайн-файлов. Для теста создай заметку, включи авиарежим, выключи Wi-Fi и заново открой приложение.

Все ресурсы локальные. Данные можно экспортировать и восстановить в разделе «Об этом». Очистка хранилища приложения может удалить заметки.
